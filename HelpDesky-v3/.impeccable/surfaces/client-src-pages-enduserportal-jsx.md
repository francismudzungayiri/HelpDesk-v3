## Direction contract

THESIS: HelpDesky feels like a native Mac app in the browser: calm grey window, translucent source-list sidebar, white inset groups, system blue for every action. It refuses bespoke "world" styling; convention is the commitment, executed at Apple's craft level.

OWN-WORLD: System font (San Francisco on Apple, Segoe UI on Windows); #F5F5F7 window ground, white 12px-radius groups with hairline shadows, #E5E5EA separators; system blue #0071E3 actions; segmented controls on #E8E8ED tracks; capsule priority tags (red, orange, green washes) and dot-plus-label statuses (blue, purple, green); dashed "Unassigned" capsule; rounded app icon with the FiLifeBuoy glyph.

STORY: People sign in on an Apple-ID-style panel, work in a queue that reads like Mail, and change state from grouped fields like System Settings, without learning anything new.

FIRST VIEWPORT: Sign-in: centred white panel, 64px app icon, "Sign in to HelpDesky", one grouped field box (Username, Password), full-width blue Sign in, account link below a hairline. Staff: translucent sidebar (app mark, Work and People sections, blue selected row, user, availability pop-up, Log out); large title "Tickets", segmented scope and views, rounded search field, white table group with #id, title, priority capsule, status dot, assignee avatar, update time.

FORM: Canon (owner-pinned), references macOS Mail, Reminders, System Settings; superseded seed 62603866.
